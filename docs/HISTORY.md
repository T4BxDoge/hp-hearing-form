## ヒアリングフォームの変遷
1. 質問15問の画面を作成 → 回答をスプシに貯めたいので **GASのウェブアプリ** に（Googleフォームより見た目を自由にできるため）
2. 写真の添付（Googleドライブに会社ごとのフォルダで保存）
3. 毎回コードを貼り直すのが面倒 → **画面（index.html）はGitHubから読み込む**方式に。質問や見た目の変更は push だけで反映
4. 料金プランに合わせて質問を作り直し、フォーム上部にプラン案内を表示
5. スプシの列を**質問から自動で作る**方式に（質問を増減しても `Code.gs` の貼り直し不要）
6. スプシのA列に「Claudeに貼る用の文章」を自動で入れる（ここに貼る → HP生成、という流れ）
7. 行の高さを固定（長文で行が高くなって見づらかったため）
8. 質問の追加・変更
   - 公開後の修正・更新を「自分で／おまかせ／簡単なものは自分で」から選ぶ。自分で更新したい人にだけ「何を更新したいか」を聞く
   - ドメイン：「持っている」→ ドメイン名・取得先・メール利用の有無、「取得してほしい」→ 希望ドメイン名（第一希望必須、第二・第三任意）
   - 色をメインカラーとサブカラーに分割
   - ロゴ「あり（データもある）」でロゴ画像を添付できる（縮小しない）
   - 写真の選択肢「わからない」→「なし」
   - デザインデモの希望を聞く質問は削除（必ず見せるため）
   - ページ構成（1ページ完結／2ページ目以降もほしい）を料金表付きで聞く。「相談して決めたい」は不要と判断して削除。2ページ目以降を選んだ人には、追加したいページ（選択式＋その他）と内容を聞き、費用の目安を自動表示
9. 条件付きの質問（`when`）、1行入力（`text`）、複数入力（`multi`）、添付（`upload`）、料金表（`price`）、費用目安（`estimate`）の仕組みを `index.html` に用意してある

## 作り方についての判断
- 1ページ完結の小さな会社・お店のサイトは **素のHTML/CSS/JS＋無料の静的ホスティング**が最適と判断。表示が速い、サーバー代0円、安全、Claudeが直接直せて月額管理の修正が速い
- WordPress はサーバー代・更新作業・セキュリティ対策の負担が大きく、このプランには不向き。ノーコード（STUDIO・Wix等）は月額料金がかかり、Claudeで作れず、iPadでの制作も難しい
- お客さんが自分で更新したい場合は「HTML＋スプシで更新」がおすすめ（未実装・保留）
- アニメーションは豊富に入れる。ただし小さい図形を拡大・細い線のSVGを回転させると iPad でぼやける・ギザギザになった（RE.sense で実際に指摘あり）→ 動く図形は canvas で端末の解像度に合わせて描く
- LINEの友だち追加URLはPCで開くとQRコードの画面になる（LINEの仕様）→ スマホはボタン、PCはページ内のQRコード
- 問い合わせ方法が「LINEのみ」の場合はフォームを置かない（RE.senseで削除を依頼された）
- デザインは**毎回5パターン**作る（王道・ミニマル・ビジュアル・やわらか・個性派）

## 公開の仕組み（RE.sense で決めたこと）
- 支払い・契約の名義は **RE.sense の会社名義**（業務提携の形に合わせ、T4Bが費用を立て替えないため。提携終了時もRE.sense側に残る）
- Cloudflare のアカウントは RE.sense の会社のメールで作成。T4B は自分のアカウントを**メンバー（Administrator＋Billing）**として招待してもらい、そこから作業
  - Administrator だけではドメインを購入できなかったため Billing を追加
  - Super Administrator は付けない（オーナーは先方だけ）
- ドメインは .com を Cloudflare Registrar で取得（.jp／.co.jp は Cloudflare では取れない）。登録者は会社名義
- 公開は Cloudflare の **Workers**（画面の流れが Pages ではなく Workers になっていたため）。サイトごとに `wrangler.jsonc` を置き、ルートディレクトリを `/sites/<slug>` にする
- 独自ドメイン（www付きも）を Workers のドメイン設定で追加。DNS・証明書は自動
- 本番ドメインが決まったら canonical・OGP・`SITE.url` を書き換え、sitemap.xml と robots.txt を置き、Google Search Console に登録（Cloudflare連携で所有権確認、会社のアカウントもオーナーに追加）
- お客さんがすでにドメインを持っている場合：ドメインは先方のまま、ネームサーバーをCloudflareに変えてもらい、公開作業はこちらでやる（IDやパスワードは預からない）

## 有料サービスの入会（RE.sense で決めたこと・2026-11-19）
- 決済は **Stripe の Payment Link（支払いリンク）** を使う。サーバー不要で、URLを `site.js` の `SITE.stripe` に入れるだけで入会ボタンが決済ページにつながる。空のときはボタンが「お申し込み準備中」になる
- 月額課金なので、特定商取引法に基づく表記・利用規約・プライバシーポリシー（リジェは紹介制度規約も）を `legal/` に置いた。代表者・住所・電話は未確定のため「請求があった場合には遅滞なく開示」の表記にしている（`SITE` に入れれば自動で差し替わる）
- 入会ボタンは「利用規約・解約条件に同意する」チェックを入れないと押せない（2022年の特商法改正の最終確認の考え方に合わせる）
- 会社情報（`SITE`）は全ページで使うため、`script.js` から `site.js` に分けた。トップは `site.js`＋`script.js`、紹介ページ・規約ページは `site.js`＋`lp.js`
- 紹介ページはいただいた画像のイメージに合わせ、トップの白基調とは別のデザイン（リジェ＝白と青、DFS＝深緑とネオン）。キャラクター・ロゴ・ノートPCの画像は、いただいた画像から切り出したもの
- 問い合わせ用メール info@resense-inc.com は Cloudflare の Email Routing（無料・受信の転送）で作る方針
