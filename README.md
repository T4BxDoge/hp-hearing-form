# hp-hearing-form

ホームページ制作のヒアリングフォーム（Google Apps Script のウェブアプリ）。

## 構成

| ファイル | 役割 | 変更したとき |
| --- | --- | --- |
| `index.html` | フォームの画面（質問・見た目・送信処理） | GitHubに反映するだけでOK。数分でフォームに反映される |
| `gas/Code.gs` | GAS本体（画面の読み込み、スプシへの保存、写真のドライブ保存） | Apps Script の `コード.gs` に貼り直して、デプロイを新バージョンで更新（質問の追加・削除だけなら不要） |

## 仕組み

- GAS の `doGet` が GitHub の `index.html`（main ブランチ）を毎回読み込んで表示する
- GitHub から読めないときは、直前に読めた版（最大6時間）→ Apps Script 内の `index` の順で使う
- 回答はスプレッドシートの「回答」シートに1社1行で追加される
- A列「コピペ用（Claudeに貼る）」に、その行の回答をまとめた文章が入る。セルをコピーしてClaudeに貼るとHP生成の材料になる
- スプシのメニュー「ヒアリング → コピペ用を作り直す」で、既存の行のA列をまとめて作り直せる
- 添付写真は Google ドライブの「HPヒアリング添付 / 日時_会社名」フォルダに保存され、スプシの「写真フォルダ」列にリンクが入る

## 注意

- このリポジトリは公開。回答データや個人情報はここに置かない
- スプシの列はフォームの各質問の列名（`c` / `col`）から自動で作られる。新しい列名は右端に追加される
